# Security Policy

## Supported Versions
We are currently focusing on the development of v0.6+.

| Version | Supported          |
| ------- | ------------------ |
| v0.6.x  | :white_check_mark: |
| v0.5.x  | :x:                |
| < v0.5  | :x:                |

## Reporting a Vulnerability
We take the security of MultiLang-ASM seriously. If you believe you have found a security vulnerability, please report it to us by creating a private issue on GitHub or contacting the maintainers directly.

Please do not report security vulnerabilities via public GitHub issues.

## Non-Security Bugs
For regular bugs, please use the standard Issue Tracker.
