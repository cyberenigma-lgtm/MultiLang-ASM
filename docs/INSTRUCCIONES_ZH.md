# 📚 完整指令參考 — 繁體中文 (MultiLang-ASM)

本指南包含多語言組譯器 **MultiLang-ASM** 支援的所有繁體中文指令，屬於 **Neuro-OS.es** 生態系統的一部分。

> MultiLang-ASM 讓您能夠使用母語撰寫組合語言程式碼，並產生與 NASM/FASM/GAS 相容的標準 ASM 程式碼。

---

## 📦 資料移動

| 繁體中文 | ASM | 說明 |
|---------|-----|------|
| `移動`, `複製` | `mov` | 在暫存器/記憶體之間移動資料 |
| `交換` | `xchg` | 交換兩個運算元的值 |
| `載入有效位址` | `lea` | 載入有效位址 |
| `零擴充` | `movzx` | 以零擴充移動 |
| `符號擴充` | `movsx` | 以符號擴充移動 |

---

| 繁體中文 | ASM | 說明 |
|---------|-----|------|
| `加`, `相加` | `add` | 兩個運算元相加 |
| `減`, `相減` | `sub` | 兩個運算元相減 |

| `有符號乘` | `imul` | 有符號乘法 |

| `遞增` | `inc` | 增加 1 |
| `遞減` | `dec` | 減少 1 |
| `取負` | `neg` | 取負 (二補數) |

## 🎯 流程控制

### 無條件跳躍

| 繁體中文 | ASM | 說明 |
|---------|-----|------|
| `跳躍` | `jmp` | 無條件跳躍 |
| `呼叫` | `call` | 呼叫副程式 |
| `返回` | `ret` | 從副程式返回 |

### 條件跳躍

| 繁體中文 | ASM | 說明 |
|---------|-----|------|
| `若相等` | `je`, `jz` | 若相等/若為零則跳躍 |
| `若不等` | `jne`, `jnz` | 若不等/若非零則跳躍 |
| `若大於` | `jg` | 若大於則跳躍 (有符號) |
| `若大於等於` | `jge` | 若大於或等於則跳躍 |
| `若小於` | `jl` | 若小於則跳躍 (有符號) |
| `若小於等於` | `jle` | 若小於或等於則跳躍 |
| `若超過` | `ja` | 若超過則跳躍 (無符號) |
| `若低於` | `jb` | 若低於則跳躍 (無符號) |

## 📚 堆疊

| 繁體中文 | ASM | 說明 |
|---------|-----|------|
| `推入` | `push` | 將值推入堆疊 |
| `彈出` | `pop` | 從堆疊彈出值 |
| `推入旗標` | `pushf` | 推入旗標暫存器 |
| `彈出旗標` | `popf` | 彈出旗標暫存器 |

---

## 📝 使用範例

```asm
; 將兩個數字相加的函式
函式_sum:
    推入 rbp               ; push rbp
    移動 rbp, rsp          ; mov rbp, rsp
    
    加 rdi, rsi            ; add rdi, rsi
    移動 rax, rdi          ; mov rax, rdi
    
    彈出 rbp               ; pop rbp
    返回                   ; ret
```

> [!TIP]
> 所有標準英文指令 (mov, add, jmp 等) 也可直接使用而無需翻譯。
