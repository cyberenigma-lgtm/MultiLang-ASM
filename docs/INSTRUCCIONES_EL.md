# MultiLang-ASM: Οδηγίες (Ελληνικά - el)

Καλώς ήρθατε στην υποστήριξη της Ελληνικής γλώσσας για το MultiLang-ASM.

## 🛠 Βασικές Εντολές

| MultiLang-ASM | NASM (x86_64) | Περιγραφή |
| :--- | :--- | :--- |
| `μετακίνηση` | `mov` | Μετακίνηση δεδομένων |
| `πρόσθεση` | `add` | Πρόσθεση |
| `αφαίρεση` | `sub` | Αφαίρεση |
| `σύγκριση` | `σύγκριση` | Σύγκριση τιμών |
| `άλμα` | `jmp` | Άλμα σε διεύθυνση |
| `κλήση` | `call` | Κλήση συνάρτησης |
| `επιστροφή` | `ret` | Επιστροφή από συνάρτηση |
| `διακοπή` | `int` | Διακοπή λογισμικού |
| `κλήση_συστήματος` | `syscall` | Κλήση πυρήνα |

## 📝 Παράδειγμα Κώδικα

```asm
; Hello World σε Ελληνικά
τμήμα .δεδομένα
    μήνυμα: db "Γεια σου κόσμε!", 10

τμήμα .κείμενο
    καθολικό _έναρξη

_έναρξη:
    μετακίνηση rax, 1          ; syscall: write
    μετακίνηση rdi, 1          ; fd: stdout
    μετακίνηση rsi, μήνυμα     ; buffer
    μετακίνηση rdx, 15         ; length
    κλήση_συστήματος

    μετακίνηση rax, 60         ; syscall: exit
    μετακίνηση rdi, 0          ; error code
    κλήση_συστήματος
```

## 🚀 Χρήση

```bash
python mlasm.py el πρόγραμμα.masm
```
