# 📚 Полный Справочник Инструкций — Русский (MultiLang-ASM)

Это руководство содержит все поддерживаемые инструкции на русском языке для многоязычного ассемблера **MultiLang-ASM**, часть экосистемы **Neuro-OS.es**.

> MultiLang-ASM позволяет писать ассемблерный код на вашем родном языке и генерировать стандартный ASM-код, совместимый с NASM/FASM/GAS.

---

## 📦 Перемещение Данных

| Русский | ASM | Описание |
|---------|-----|----------|
| `перенести` | `mov` | Переместить данные между регистрами/памятью |
| `обменять` | `xchg` | Обменять значения между операндами |
| `загрузить_эффективный` | `lea` | Загрузить эффективный адрес |
| `расширить_нулями` | `movzx` | Переместить с расширением нулями |
| `расширить_знаком` | `movsx` | Переместить с расширением знаком|

---

## ➕ Арифметика

| Русский | ASM | Описание |
|---------|-----|----------|
| `добавить`, `сложить` | `add` | Сложить два операнда |
| `вычесть` | `sub` | Вычесть два операнда |
| `умножить` | `mul` | Умножение без знака |
| `умножить_знак` | `imul` | Умножение со знаком |
| `разделить` | `div` | Деление без знака |
| `разделить_знак` | `idiv` | Деление со знаком |
| `увеличить` | `inc` | Увеличить на 1 |
| `уменьшить` | `dec` | Уменьшить на 1 |
| `отрицание` | `neg` | Отрицание (дополнение до 2) |

---

## 🔢 Логические Операции

| Русский | ASM | Описание |
|---------|-----|----------|
| `и` | `and` | Логическое И побитово |
| `или` | `or` | Логическое ИЛИ побитово |
| `не` | `not` | Логическое НЕ (дополнение до 1) |
| `исключающее` | `xor` | Исключающее ИЛИ побитово |
| `сдвиг_влево` | `shl`, `sal` | Логический/арифметический сдвиг влево |
| `сдвиг_вправо` | `shr`, `sar` | Логический/арифметический сдвиг вправо |
| `вращать_влево` | `rol` | Вращение влево |
| `вращать_вправо` | `ror` | Вращение вправо |

|---------|-----|----------|

| `проверить` | `test` | Логическое И без сохранения результата |

## 🎯 Управление Потоком

### Безусловные Переходы

| Русский | ASM | Описание |
|---------|-----|----------|
| `прыгнуть` | `jmp` | Безусловный переход |
| `вызвать` | `call` | Вызвать подпрограмму |
| `вернуться` | `ret` | Вернуться из подпрограммы |

### Условные Переходы

| Русский | ASM | Описание |
|---------|-----|----------|
| `если_равно` | `je`, `jz` | Перейти если равно / если ноль |
| `если_не_равно` | `jne`, `jnz` | Перейти если не равно / если не ноль |
| `если_больше` | `jg` | Перейти если больше (со знаком) |
| `если_больше_равно` | `jge` | Перейти если больше или равно |
| `если_меньше` | `jl` | Перейти если меньше (со знаком) |
| `если_меньше_равно` | `jle` | Перейти если меньше или равно |
| `если_выше` | `ja` | Перейти если выше (без знака) |
| `если_ниже` | `jb` | Перейти если ниже (без знака) |

## 📚 Стек

| Русский | ASM | Описание |
|---------|-----|----------|
| `положить` | `push` | Поместить значение в стек |
| `извлечь` | `pop` | Извлечь значение из стека |
| `положить_флаги` | `pushf` | Поместить регистр флагов |
| `извлечь_флаги` | `popf` | Извлечь регистр флагов |

---

## 📝 Пример Использования

```asm
; Функция которая складывает два числа
функция_сумма:
    положить rbp            ; push rbp
    перенести rbp, rsp      ; mov rbp, rsp
    
    добавить rdi, rsi       ; add rdi, rsi
    перенести rax, rdi      ; mov rax, rdi
    
    извлечь rbp             ; pop rbp
    вернуться               ; ret
```

> [!TIP]
> Все стандартные инструкции на английском (mov, add, jmp и т.д.) также работают напрямую без перевода.
