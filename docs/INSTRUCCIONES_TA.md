# MultiLang-ASM: அறிவுறுத்தல்கள் (தமிழ் - ta)

MultiLang-ASM இன் தமிழ் ஆதரவிற்கு வரவேற்கிறோம்.

## 🛠 அடிப்படை கட்டளைகள்

| MultiLang-ASM | NASM (x86_64) | விளக்கம் |
| :--- | :--- | :--- |
| `நகர்த்து` | `mov` | தரவை நகர்த்து |
| `கூட்டு` | `add` | மதிப்பை கூட்டு |
| `கழி` | `sub` | மதிப்பை கழி |
| `ஒப்பிடு` | `cmp` | மதிப்புகளை ஒப்பிடு |
| `தாவு` | `jmp` | முகவரிக்கு தாவு |
| `அழை` | `call` | செயல்பாட்டை அழை |
| `திரும்பு` | `ret` | செயல்பாட்டிலிருந்து திரும்பு |
| `தடை` | `int` | மென்பொருள் தடை |
| `அமைப்பு_அழைப்பு` | `syscall` | சிஸ்டம் கால் |

## 📝 குறியீடு எடுத்துக்காட்டு

```asm
; தமிழில் ஹலோ வேர்ல்ட்
பகுதி .data
    செய்தி: db "Hello World!", 10

பகுதி .text
    global _start

_start:
    நகர்த்து rax, 1          ; syscall: write
    நகர்த்து rdi, 1          ; fd: stdout
    நகர்த்து rsi, செய்தி      ; buffer
    நகர்த்து rdx, 13         ; length
    அமைப்பு_அழைப்பு

    நகர்த்து rax, 60         ; syscall: exit
    நகர்த்து rdi, 0          ; exit code
    அமைப்பு_அழைப்பு
```
