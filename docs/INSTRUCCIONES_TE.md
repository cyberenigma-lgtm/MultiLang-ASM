# MultiLang-ASM: సూచనలు (తెలుగు - te)

MultiLang-ASM తెలుగు మద్దతుకు స్వాగతం.

## 🛠 ప్రాథమిక ఆదేశాలు

| MultiLang-ASM | NASM (x86_64) | వివరణ |
| :--- | :--- | :--- |
| `మార్చు` | `mov` | డేటాను తరలించు |
| `కలుపు` | `add` | విలువను కలుపు |
| `తీసివేయి` | `sub` | విలువను తీసివేయి |
| `పోల్చు` | `cmp` | విలువలను పోల్చు |
| `దూకు` | `jmp` | చిరునామాకు దూకు |
| `పిలువు` | `call` | ఫంక్షన్‌ను పిలువు |
| `తిరిగి_రా` | `ret` | ఫังก์ชัน నుండి తిరిగి రా |
| `అంతరాయం` | `int` | సాఫ్ట్‌వేర్ అంతరాయం |
| `సిస్టమ్_కాల్` | `syscall` | సిస్టమ్ కాల్ |

## 📝 కోడ్ ఉదాహరణ

```asm
; తెలుగులో హలో వరల్డ్
విభాగం .data
    సందేశం: db "Hello World!", 10

విభాగం .text
    global _start

_start:
    మార్చు rax, 1          ; syscall: write
    మార్చు rdi, 1          ; fd: stdout
    మార్చు rsi, సందేశం      ; buffer
    మార్చు rdx, 13         ; length
    సిస్టమ్_కాల్

    మార్చు rax, 60         ; syscall: exit
    మార్చు rdi, 0          ; exit code
    సిస్టమ్_కాల్
```

## 🚀 వాడకం

```bash
python mlasm.py te ప్రోగ్రామ్.masm
```
