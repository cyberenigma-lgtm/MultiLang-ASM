# 📚 完全な命令リファレンス — 日本語 (MultiLang-ASM)

このガイドには、多言語アセンブラ **MultiLang-ASM** でサポートされているすべての日本語命令が含まれています。**Neuro-OS.es** エコシステムの一部です。

> MultiLang-ASMを使用すると、母国語でアセンブリコードを記述し、NASM/FASM/GASと互換性のある標準ASMコードを生成できます。

---

## 📦 データ移動

| 日本語 | ASM | 説明 |
|---------|-----|------|
| `移動`, `コピー` | `mov` | レジスタ/メモリ間でデータを移動 |
| `交換` | `xchg` | オペランド間で値を交換 |
| `実効アドレス読込` | `lea` | 実効アドレスを読み込む |
| `ゼロ拡張` | `movzx` | ゼロ拡張して移動 |
| `符号拡張` | `movsx` | 符号拡張して移動 |

## 📝 使用例

```asm
; 2つの数を加算する関数
関数_合計:
    プッシュ rbp            ; push rbp
    移動 rbp, rsp           ; mov rbp, rsp
    
    加算 rdi, rsi           ; add rdi, rsi
    移動 rax, rdi           ; mov rax, rdi
    
    ポップ rbp              ; pop rbp
    戻る                    ; ret
```

> [!TIP]
> すべての標準英語命令 (mov, add, jmp など) も翻訳なしで直接機能します。
