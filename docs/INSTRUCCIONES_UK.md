# MultiLang-ASM: Інструкції (Українська - uk)

Ласкаво просимо до української підтримки MultiLang-ASM.

## 🛠 Основні команди

| MultiLang-ASM | NASM (x86_64) | Опис |
| :--- | :--- | :--- |
| `перенести` | `mov` | Переміщення даних |
| `додати` | `add` | Додавання |
| `відняти` | `sub` | Віднімання |
| `порівняти` | `cmp` | Порівняння значень |
| `стрибнути` | `jmp` | Перехід за адресою |
| `викликати` | `call` | Виклик функції |
| `повернутися` | `ret` | Повернення з функції |
| `переривання` | `int` | Програмне переривання |
| `системний_виклик`| `syscall` | Системний виклик |

## 📝 Приклад коду

```asm
; Привіт світ українською
секція .data
    повідомлення: db "Pryvit svite!", 10

секція .text
    глобальний _start

_start:
    перенести rax, 1          ; syscall: write
    перенести rdi, 1          ; fd: stdout
    перенести rsi, повідомлення ; buffer
    перенести rdx, 14         ; length
    системний_виклик

    перенести rax, 60         ; syscall: exit
    перенести rdi, 0          ; код помилки
    системний_виклик
```

## 🚀 Використання

python mlasm.py uk програма.masm
