## 🤝 Contribute

Want to add your language? We need native speakers to help create accurate, natural instruction references.

1. Copy an existing reference file
2. Translate instructions following the [language design philosophy](INSTRUCCIONES_ES.md#🎨-diseño-del-lenguaje-en-español)
3. Submit a pull request

**Principles:**
- **Naturalness over Literality** - Use terms that sound natural to native speakers
- **Clarity over Brevity** - Prefer clear, descriptive names
- **Linguistic Consistency** - Maintain coherence across instruction families
