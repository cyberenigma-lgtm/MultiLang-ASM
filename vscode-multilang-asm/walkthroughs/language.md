# 🌍 El Mundo es tu Código

Soportamos **27 idiomas** y docenas de dialectos regionales.

## Configuración
Para cambiar tu idioma principal:
1.  Abre la configuración (`Ctrl+,`).
2.  Busca `MultiLang-ASM`.
3.  Selecciona tu idioma en el menú desplegable.

### Idiomas Disponibles
Español, Inglés, Francés, Alemán, Italiano, Portugués, Ruso, Japonés, Chino, Árabe... ¡y muchos más!

## Dialectos Divertidos
Prueba los dialectos regionales como:
*   🇬🇧 **Cockney**: `pinch` (restar), `scarper` (saltar)
*   🇯🇵 **Kansai**: `misete` (print)
